# Sistem Informasi Geografis Persebaran SPBU Kota Semarang

Quantum GIS (Geographic Information System) untuk memetakan persebaran SPBU (Stasiun Pengisian Bahan Bakar Umum) di Kota Semarang. Proyek ini merupakan aplikasi web interaktif yang memungkinkan pengguna melihat lokasi SPBU secara geografis, melakukan pencarian, dan analisis spasial sederhana.

---

## ✨ Fitur Utama

- **Visualisasi Peta Interaktif:** Menampilkan persebaran SPBU di Kota Semarang menggunakan peta digital.
- **Pencarian Lokasi SPBU:** Pengguna dapat mencari SPBU berdasarkan nama, alamat, atau wilayah.
- **Detail Informasi SPBU:** Menyediakan informasi detail setiap SPBU, seperti alamat, jenis bahan bakar, dan fasilitas.
- **Analisis Spasial Sederhana:** Fitur analisis jarak, area terdekat, dan rute menuju SPBU.
- **Tampilan User-Friendly:** Desain antarmuka menggunakan HTML, CSS, dan JavaScript untuk pengalaman pengguna yang optimal.

## 🚀 Instalasi & Penggunaan

1. **Clone repository ini:**
    ```bash
    git clone https://github.com/agusbayu13/Sistem-Informasi-Geografis-Persebaran-SPBU-Kota-Semarang.git
    ```
2. **Buka folder proyek:**
    ```bash
    cd Sistem-Informasi-Geografis-Persebaran-SPBU-Kota-Semarang
    ```
3. **Jalankan file `index.html` di browser Anda untuk memulai aplikasi.**

### Prasyarat

- Tidak memerlukan backend, cukup web browser modern.
- Untuk pengembangan lebih lanjut, pastikan sudah terinstal [QGIS](https://qgis.org/) jika ingin mengolah data GIS.
